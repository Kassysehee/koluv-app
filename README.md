# KoLuv 한옥마을 — 데스크탑 앱

3D 한옥마을을 걸어서 강의실·복습실·카페로 들어가는 데스크탑 앱입니다.

**설치 파일은 [Releases](../../releases/latest) 에서 받으세요.**

> 이 저장소는 **설치 파일 배포 전용**입니다. 소스 코드는 포함되어 있지 않습니다.

## macOS

- macOS 14 이상 · **Apple Silicon (M1 이후)**
- 처음 실행할 때는 앱을 **우클릭 → 열기** 로 여세요 (Apple 공증 전)

## Windows

준비 중입니다.
